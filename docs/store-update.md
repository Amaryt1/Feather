# تحديث AMARYT STORE

انشر تغييرات لوحة Mstoda أولًا، ثم وزّع يدويًا نسخة المتجر التي تحتوي على فاحص التحديث.
النسخ الأقدم لا تقرأ ملف store-update.json. يبدأ ملف النشر فارغًا.

ارفع IPA إلى GitHub Releases عام بحساب Amaryt1. من «تحديث المتجر» أدخل الرابط
والإصدار المطابق لـ CFBundleShortVersionString. حدّد CFBundleVersion عند نشر بناء
جديد بنفس الإصدار. بعد تأكيد GitHub افحص الملف المنشور على main.
التطبيق يفحصه عند التشغيل والعودة، ويحتفظ بآخر قرار صحيح عبر انقطاع الاتصال.
عند أول تشغيل دون اتصال أو سياسة محفوظة، يفتح المتجر بعد محاولة الاتصال.
تراجع الإدارة يلغي القيد أو يعيده إلى الإصدار السابق عند وصول القرار للجهاز.

تتطلب الترقية نفس معرّف المتجر المثبّت وهوية التطبيق وفريق التوقيع، وملف تزويد
يسمح بالحزمة وامتداداتها. يمكن إضافة الشهادة أو اختيارها وفتح إعدادات الثقة من
شاشة التحديث. للمحرك المحلي هوية HTTPS خاصة بالجهاز وقد تتطلب تثبيت ملف الثقة.
تبقى الحزمة متاحة محليًا بعد إرسال الطلب. يقرر iOS قبول التثبيت، ويمكن أن يوقف النظام
المتجر أثناء الاستبدال. افتح المتجر بعد التحديث للتحقق من الإصدار.
اختبر على جهاز فعلي بنفس طريقة توزيع النسخة الأصلية، مع شهادة موجودة وأخرى
مضافة من النافذة، وانقطاع الاتصال قبل وبعد اكتشاف الإجبار، ومع بقاء المكتبة والشهادات.
